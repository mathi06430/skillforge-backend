# SkillForge - Backend

Backend API for SkillForge - a skill-sharing and learning platform.

## 🚀 Tech Stack
- FastAPI (Python)
- SQLAlchemy + SQLite
- Pydantic

## ✨ Features
- User authentication
- Skill creation & management
- Database models for users & skills

## 🛠️ How to run locally

```bash
git clone https://github.com/YOUR_USERNAME/skillforge-backend.git
cd skillforge-backend
pip install -r requirements.txt
uvicorn main:app --reload
